# Release & Package Manager Distribution

This guide describes how to publish NodeStats CLI releases and distribute packages via **Homebrew**, **APT** (Debian/Ubuntu), and **DNF/RPM** (Fedora/RHEL).

## 1. Make the Repository Public

Homebrew (`homebrew-core` and public taps) and Linux package managers fetch release tarballs anonymously over HTTPS. Ensure `https://github.com/baranyaigabor/NodeStats` is set to **Public** before tagging a release or opening a `homebrew-core` PR.

## 2. Publishing a Release (`v*`)

Bump `version` in `Cargo.toml` and `CHANGELOG.md`, then tag and push:

```sh
git tag -s v0.2.5 -m "v0.2.5"
git push origin main v0.2.5
```

`.github/workflows/release.yml` builds and attaches to the GitHub Release:
- `nodestats-<ver>-linux-amd64.tar.gz`, `nodestats-<ver>-linux-arm64.tar.gz` (static musl binaries)
- `.deb` packages (`cargo-deb`) for `amd64` and `arm64`
- `.rpm` packages (`cargo-generate-rpm`) for `x86_64` and `aarch64`
- `nodestats-<ver>-macos-arm64.tar.gz`, `nodestats-<ver>-macos-x64.tar.gz`, and `.pkg` installers
- `nodestats-<ver>-windows-x64.exe`, `nodestats-<ver>-windows-arm64.exe`
- `nodestats-<ver>-SHA256SUMS.txt`

## 3. Setting up Signed APT & DNF/RPM Repositories on GitHub Pages

1. Generate (or reuse) a dedicated GPG signing key for APT/RPM packages (`gpg --quick-generate-key "NodeStats Packages <baranyaigl06@gmail.com>" rsa4096 sign 0`).
2. Add the armored private key to GitHub Repository Secrets as `APT_GPG_PRIVATE_KEY` (`gpg --armor --export-secret-keys <KEY_ID>`), and passphrase if any as `APT_GPG_PASSPHRASE`.
3. Enable **GitHub Pages** from the `gh-pages` branch in repository Settings → Pages.

Every `v*` release automatically updates:
- `https://baranyaigabor.github.io/NodeStats/apt/` (`InRelease`, `Release.gpg`, `Packages.gz`, `gpg.key`)
- `https://baranyaigabor.github.io/NodeStats/rpm/` (`repodata/`, `repomd.xml.asc`, `gpg.key`)

## 4. Homebrew Distribution (`brew install nodestats`)

### Official `homebrew-core` Formula

Use `packaging/homebrew/nodestats.rb`:
1. Download the GitHub source tarball for the tag and compute its SHA-256:
   ```sh
   curl -fsSL https://github.com/baranyaigabor/NodeStats/archive/refs/tags/v0.2.5.tar.gz | shasum -a 256
   ```
2. Put that hash in `packaging/homebrew/nodestats.rb`.
3. Fork `Homebrew/homebrew-core`, copy the formula to `Formula/n/nodestats.rb`, and verify strictly:
   ```sh
   brew audit --strict --new nodestats
   brew install --build-from-source nodestats
   brew test nodestats
   ```
4. Open a PR to `Homebrew/homebrew-core` once the repository meets Homebrew's public release and notability criteria (`>= 75` GitHub stars / `>= 30` forks or notable adoption).

### Personal Tap (`baranyaigabor/homebrew-tap`) — Instant Availability

Until `homebrew-core` accepts the formula, host `packaging/homebrew/nodestats-tap.rb` as `Formula/nodestats.rb` in a public `baranyaigabor/homebrew-tap` repo and add a `HOMEBREW_TAP_TOKEN` secret (`repo` scope) to auto-compute release SHA-256 checksums on every tag:

```sh
brew install baranyaigabor/tap/nodestats
```

## 5. Native Distro Repositories (Zero Custom Repo Setup)

- **Fedora COPR**: Upload the `.spec` or SRPM generated by `cargo-generate-rpm` to COPR (`sudo dnf copr enable baranyaigabor/nodestats && sudo dnf install nodestats`).
- **Arch AUR**: Maintain a `nodestats-bin` `PKGBUILD` pointing to `nodestats-<ver>-linux-amd64.tar.gz` and its SHA-256 checksum.
